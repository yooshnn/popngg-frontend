# `shared/i18n`

```ts
import { fallbackLanguage, localeCookie, supportedLanguages } from '~/shared/i18n';
import type { SupportedLanguage } from '~/shared/i18n';
```

Component usage — plain `react-i18next`, nothing custom:

```tsx
import { useTranslation } from 'react-i18next';

const { t, i18n } = useTranslation();
t('demo');
await i18n.changeLanguage('ja');   // call on the hook's i18n directly
```

Switching language + persisting the choice:

```ts
await localeCookie.write(lng);
await i18n.changeLanguage(lng);
await revalidate(); // react-router useRevalidator
```

Root wiring (`root.tsx`): `middleware = [apiMiddleware, i18nextMiddleware]`.
Server-side instance/translation inside a loader:

```ts
import { getInstance } from '~/shared/i18n/middleware';

getInstance(context).t('demo');
```

Adding strings: `apps/main/app/shared/i18n/resources/{ko,ja}/common.ts`.
